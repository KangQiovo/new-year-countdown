# 新年倒计时部署说明

本项目由一个静态前端(`index.html`)和一个轻量 Node.js 后端(`server.js`)组成，后端负责广播祝福与时间心跳。无需把 Node.js 安装在站点目录内——只需在服务器全局安装 Node.js（建议 LTS 版本），即可在项目目录运行服务。

## 环境要求
- Node.js (建议 18+，全局安装即可)
- npm 或 pnpm 用于安装依赖

## 部署步骤
1. **拉取代码**：将代码放置在任意站点目录，例如 `/var/www/new-year/`。
2. **安装依赖**：在项目根目录执行 `npm install`（仅需一次，用于安装 Express 与 ws）。
3. **启动服务**：运行 `npm start` 或 `node server.js`，默认监听 `PORT` 环境变量或 `3000` 端口。
4. **反向代理（可选）**：使用 Nginx/Apache 将公网域名反代到上述端口，并开启 HTTPS。
5. **守护进程（可选）**：使用 pm2/systemd 等方式托管 `npm start`，确保跨年期间稳定运行。

## 宝塔面板部署示例
> 适用于常见的宝塔 Linux 面板，假设已在服务器上安装好 Node.js（可通过「软件商店」或手动安装）。

1. **上传代码**：在「文件」中上传项目到目标目录（如 `/www/wwwroot/new-year/`），或通过 SFTP/`git clone` 方式放到该目录。
2. **安装依赖**：进入「终端」或「远程 SSH」，切换到项目目录执行 `npm install`。
3. **配置 Node 项目/守护**：
   - 如果安装了「PM2 管理器」插件：新增应用，执行命令填 `npm start`（工作目录指向项目根），端口填 `3000` 或你的自定义端口，并开启开机自启。
   - 若无插件，可在终端使用 `npm install -g pm2 && pm2 start server.js --name new-year --watch`，再 `pm2 save` + `pm2 startup` 持久化。
4. **添加反向代理/站点**：在「网站」中新建站点选择反向代理，目标填写 `http://127.0.0.1:3000`（或你的端口），开启 HTTPS/HTTP2 与缓存压缩，记得放行防火墙端口。
5. **日志与更新**：
   - PM2 日志：`pm2 logs new-year` 查看后端输出。
   - 更新代码后在项目目录执行 `git pull`（或重新上传），再运行 `npm install`（如有依赖变化）并 `pm2 restart new-year`。

## 目录结构
```
/项目根目录
├─ index.html     # 前端单页，包含倒计时、祝福弹幕、烟花动画
├─ server.js      # Node.js 后端，静态资源与 WebSocket 广播
└─ package.json   # 启动脚本与依赖
```

## 常见问题
- **必须把 Node.js 安装在网站目录吗？** 不需要。Node.js 安装一次即可，在服务器全局可执行后，在项目目录运行 `npm start` 即可。
- **可以把前后端放不同目录吗？** 可以，但需调整 `server.js` 中的静态目录路径或使用反向代理。默认配置假定前后端在同一项目根目录，便于直接部署。
- **想改端口？** 设置环境变量 `PORT=8080 npm start` 即可。
